# Roadmap

## v0.1.0-alpha candidate

An installable offline CLI, reusable parsers, verified compact-target derivatives/extraction, independent status records, synthetic regressions and a sanitized Disc 01 case study. There is no public Git history yet; publication remains a separate review decision.

## Next: independent Disc 02 pilot

Follow [DISC02_PILOT_PLAN.md](DISC02_PILOT_PLAN.md) with a new identity and independently recorded geometry/artifacts. Repeat offline analysis before proposing any additional physical reads or recovered execution. An honest partial outcome is a valid preservation finding.

## Candidate improvements

- Reviewed append-only catalog migration/writer commands with snapshots and idempotent observation IDs.
- Stronger parser process limits, cancellation, output quotas and hostile-input fixtures.
- Independently validated portable graphical-session setup with explicit approval boundaries, reliable event/screenshot capture and clear pause/save/multiplayer instructions.
- Reference-based authenticity checks with named trusted sources and version distinctions.
- Further track/namespace/archive support only after representative synthetic fixtures and a documented geometry/security model.

## Explicitly outside this release

Automatic optical retries, automatic recovered execution or installation, a general-purpose secure emulator launcher, full-game/audio certification, proprietary content distribution and a public museum/export service. Any future publication path requires a deliberate rights-reviewed allowlist.
