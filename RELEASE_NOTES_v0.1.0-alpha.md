# RE Preservation v0.1.0-alpha

This first alpha makes the offline preservation baseline installable as `replay-preservation` (Python metadata `0.1.0a0`). It covers verified local artifacts, ddrescue map/domain analysis, cooked ISO/Joliet sector coverage, compact target integration, static package checks and scoped human compatibility evidence.

Included are synthetic regression fixtures, an independent-status schema, a repository-local preservation skill, a Disc 02 pilot plan and a sanitized DOOM II case study. No game payload, disc image, saved game, private catalog, acquisition log or execution authorization is distributed.

The alpha does not perform optical acquisition, automatically install tools, launch recovered programs, supply a portable emulator sandbox, authenticate historical publisher releases or certify a full game's functionality. The case study supports limited MAP01 interaction only; pause, audio and other capabilities remain limited as documented.

MIT covers original project materials, not third-party game content. This candidate is prepared for review; no Git commit, push, tag, GitHub release or package-index upload has occurred. Consult [readiness](PUBLIC_RELEASE_READINESS.md), [security audit](PUBLIC_SECURITY_AUDIT.md) and [first-push plan](FIRST_PUSH_PLAN.md) before authorizing publication.
